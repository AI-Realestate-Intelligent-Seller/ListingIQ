## To download the hero slideshow images

Visit each Pexels URL above, click the Free Download button, and save the file
to `frontend/public/images/` using the filename in the "Local file" column.

Until you download them, the hero will fall back to `home-exterior.jpg` for all slides.

License and usage terms should be rechecked before a final public launch.
